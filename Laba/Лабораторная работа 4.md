4. Содержимое robots.txt с пояснениями
text
User-agent: *
Allow: /
Disallow: /admin/
Disallow: /cart/
Disallow: /checkout/
Disallow: /search/
Disallow: /?utm_
Disallow: /?from=

User-agent: Yandex
Allow: /
Disallow: /admin/
Disallow: /cart/
Disallow: /checkout/
Disallow: /search/
Clean-param: utm_source&utm_medium&utm_campaign&utm_content&utm_term

User-agent: Googlebot
Allow: /
Disallow: /admin/
Disallow: /cart/
Disallow: /checkout/
Disallow: /search/

Host: https://example.ru
Sitemap: https://example.ru/sitemap.xml
Пояснения к директивам:

Allow: / — разрешает индексацию основного контента.

Disallow — закрывает служебные страницы (корзина, оформление заказа, поиск, админка) и страницы с GET-параметрами UTM, чтобы избежать появления дублей.

Clean-param (директива Яндекса) — сообщает роботу, что UTM-метки не влияют на контент страницы, поэтому сканировать их не нужно.

Host — указывает главное зеркало сайта.

Sitemap — указывает полный путь к карте сайта.

7. Ответы на контрольные вопросы
Что такое семантическое ядро и зачем оно нужно? Это упорядоченный набор поисковых запросов, по которым сайт должен находиться в выдаче. Оно необходимо для понимания структуры сайта, создания релевантных страниц и их правильной оптимизации под поисковые системы.

Чем отличаются ВЧ, СЧ и НЧ запросы? ВЧ (высокочастотные) — самые популярные запросы с высокой конкуренцией. НЧ (низкочастотные) — редкие запросы, которые легче вывести в топ. СЧ (среднечастотные) занимают промежуточное положение.

Как кластеризовать запросы? Какие методы существуют? Кластеризация — это группировка запросов по смыслу. Основные методы: ручной (по логике), по топ-выдаче (сравнение сайтов в поиске) и по леммам (по общим корням слов).

Какие директивы используются в robots.txt? User-agent (указание робота), Allow (разрешение), Disallow (запрет), Sitemap (карта сайта), Host (главное зеркало), Clean-param (игнорирование GET-параметров).

Для чего нужен Clean-param и как он работает в Яндексе? Он указывает роботу, какие параметры в URL (например, UTM-метки) не влияют на контент. Это предотвращает создание дублей страниц при переходе по рекламным ссылкам.

Какие обязательные элементы есть в sitemap.xml? Обязательным является только тег <loc> (адрес страницы). Теги <lastmod>, <changefreq>, <priority> являются дополнительными.

Как связаны кластеры СЯ и структура URL? Каждый кластер семантического ядра соответствует определенной странице или разделу сайта. Например, кластер «Ванная» получает URL /bathroom/.

Какие теги <head> отвечают за SEO-оптимизацию страницы? <title> (заголовок), <meta name="description"> (описание), <meta name="viewport"> (адаптивность), <link rel="canonical"> (главная версия), а также OpenGraph-теги.

Что такое rel="canonical" и когда его применяют? Тег, указывающий главную версию страницы при наличии дублей (например, страницы с параметрами фильтров). Он помогает избежать внутренней конкуренции.

Как проверить корректность robots.txt и sitemap.xml? robots.txt проверяется в панелях вебмастеров (Яндекс, Google). sitemap.xml проверяется через XML-валидаторы (например, xml-sitemaps.com).
