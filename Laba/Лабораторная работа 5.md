Тема: Адаптивный дизайн и UX-аудит

1. Цель работы
Изучить принципы создания адаптивного дизайна с помощью медиа-запросов, провести UX-аудит интерфейса, а также реализовать дополнительные возможности для улучшения пользовательского опыта (смена темы, бургер-меню, настройка шрифта).

2. Задание 2.2. Добавление адаптивности
В ходе работы были определены три основных брейкпоинта с использованием медиа-запросов:

≥1024px (Десктоп) — элементы располагаются в несколько колонок, используется горизонтальное меню.

768–1023px (Планшет) — сетка элементов перестраивается, сохраняется горизонтальное меню (если хватает места).

<768px (Мобильный) — все элементы выстраиваются в одну колонку, навигация скрывается под кнопку-бургер.

Для сеток использованы свойства display: flex и display: grid, которые автоматически подстраиваются под ширину экрана.

3. Задание 2.4. Реализация дополнительных возможностей
3.1. Переключатель темы «День/Ночь»
В шапку сайта добавлена кнопка с иконкой солнца/луны. При клике на <body> добавляется класс theme-dark. Цвета фона и текста заданы через CSS-переменные (:root), которые меняются в зависимости от класса. Выбор пользователя сохраняется в localStorage и восстанавливается при перезагрузке страницы. Добавлен плавный переход transition.

3.2. Бургер-меню с клавиатурной доступностью
На экранах меньше 768px навигация сворачивается в кнопку-бургер. Меню открывается по клику и с клавиатуры (Enter/Space), закрывается по клавише Esc. При открытии фокус переходит на первый пункт меню, при закрытии возвращается на кнопку. Проставлены атрибуты aria-expanded и aria-controls. У кнопок есть видимый :focus-visible.

3.3. Переключатель «Обычный / Крупный шрифт»
Рядом с кнопкой темы добавлены кнопки A+ и A-. Шрифт масштабируется до 3 уровней (100%, 125%, 150%) через класс на теге <html>. Выбор сохраняется в localStorage. При увеличении до 150% проверено отсутствие горизонтального скролла и обрезания текста.

4. Задание 2.5. «Скорость = деньги»
При загрузке страницы в DevTools (вкладка Network) замерено время ответа. Было выяснено, что задержка загрузки даже на 1–2 секунды напрямую влияет на конверсию: пользователи уходят с сайта, не дождавшись загрузки, что снижает количество заявок и звонков. Оптимизация изображений и кода критически важна для удержания клиента.

script.js

javascript
// 1. ЛОГИКА СМЕНЫ ТЕМЫ (ДЕНЬ/НОЧЬ)
const themeToggle = document.getElementById('theme-toggle');
const body = document.body;

// Проверяем сохраненную тему при загрузке
if (localStorage.getItem('theme') === 'dark') {
    body.classList.add('theme-dark');
    themeToggle.textContent = '☀️';
}

themeToggle.addEventListener('click', () => {
    body.classList.toggle('theme-dark');
    if (body.classList.contains('theme-dark')) {
        themeToggle.textContent = '☀️';
        localStorage.setItem('theme', 'dark');
    } else {
        themeToggle.textContent = '🌙';
        localStorage.setItem('theme', 'light');
    }
});

// 2. ЛОГИКА БУРГЕР-МЕНЮ С КЛАВИАТУРНОЙ ДОСТУПНОСТЬЮ
const burger = document.getElementById('burger');
const nav = document.getElementById('nav-menu');

burger.addEventListener('click', () => {
    const isExpanded = burger.getAttribute('aria-expanded') === 'true';
    burger.setAttribute('aria-expanded', !isExpanded);
    nav.classList.toggle('active');
    
    // Фокус на первое меню при открытии
    if (!isExpanded) {
        nav.querySelector('a').focus();
    }
});

// Закрытие меню по Esc
document.addEventListener('keydown', (e) => {
    if (e.key === 'Escape' && nav.classList.contains('active')) {
        nav.classList.remove('active');
        burger.setAttribute('aria-expanded', 'false');
        burger.focus(); // Возвращаем фокус на бургер
    }
});

// 3. ЛОГИКА РАЗМЕРА ШРИФТА (3 УРОВНЯ)
let currentFontSize = parseInt(localStorage.getItem('fontSize')) || 0;
const html = document.documentElement;

function applyFontSize() {
    html.className = ''; // Сброс классов
    if (currentFontSize === 1) html.classList.add('font-large-1');
    if (currentFontSize === 2) html.classList.add('font-large-2');
}

// Применяем сохраненный размер при загрузке
applyFontSize();

function changeFont(direction) {
    currentFontSize += direction;
    if (currentFontSize < 0) currentFontSize = 0;
    if (currentFontSize > 2) currentFontSize = 2;
    
    applyFontSize();
    localStorage.setItem('fontSize', currentFontSize);
}
6. Ответы на контрольные вопросы
Какие события браузера подходят для отслеживания активности?
Для отслеживания активности подходят события мыши (click, mouseover), события клавиатуры (keydown, keyup), события форм (submit, change) и события сенсорных экранов (touchstart, touchend).

Как реализовать адаптивную вёрстку под три брейкпоинта?
Нужно использовать CSS-медиазапросы (@media). Базовые стили пишутся для мобильных устройств (Mobile First), а затем с помощью @media (min-width: 768px) и @media (min-width: 1024px) добавляются стили для планшетов и десктопов соответственно.

Как работает переключение темы (день/ночь)?
Темы реализуются через CSS-переменные. В :root задаются цвета для светлой темы, а в классе .theme-dark они переопределяются. JavaScript при клике на кнопку добавляет/удаляет класс theme-dark у тега <body>, а выбор сохраняет в localStorage.

Что такое «дребезг» событий и почему это плохо?
Дребезг (debounce) — это ситуация, когда одно действие пользователя (например, прокрутка или ввод текста) вызывает слишком много срабатываний события за короткое время. Это плохо, потому что сильно нагружает браузер и процессор, вызывая зависания. Для решения используют функции throttle и debounce.

Как безопасно обновлять DOM при логировании событий?
Безопасно обновлять DOM через методы textContent (для текста) или createElement и appendChild. Нельзя использовать innerHTML с непроверенными данными, так как это может привести к XSS-атакам. Также следует минимизировать количество прямых обращений к DOM, группируя изменения.
